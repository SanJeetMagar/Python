# Python Projects Collection

A collection of Python scripts demonstrating various programming concepts and practical applications.

## 📁 Projects Overview

### 1. **Advance Password Checker** (`Advance_passwordchecker.py`)
Advanced password validation utility that checks password strength based on multiple criteria.
- Validates password complexity
- Checks for uppercase, lowercase, digits, and special characters
- Provides feedback on password strength

### 2. **ATM Simulation** (`Atm_simulation.py`)
A simple ATM (Automated Teller Machine) simulator with basic banking operations.
- **Features:**
  - Check account balance
  - Deposit money
  - Withdraw money
  - Exit the application
- Includes transaction validation

### 3. **Like or Dislike** (`LikeorDislike.py`)
Interactive application for collecting user preferences.
- Simple yes/no or like/dislike voting system
- User interaction and feedback

### 4. **Multiplication Table** (`multiplication_table.py`)
Generates and displays multiplication tables.
- Takes user input for the number
- Generates multiplication table up to a specified range
- Educational tool for learning multiplication

### 5. **Password Generator** (`password_generator.py`)
Generates secure random passwords with customizable options.
- **Features:**
  - Configurable password length
  - Options for uppercase, lowercase, digits, and special characters
  - Evaluates password strength
  - Uses Python's `random` and `string` modules

### 6. **Rock, Scissors, Paper Game** (`RSP_Game.py`)
Classic Rock, Scissors, Paper game against the computer.
- **Features:**
  - Play multiple rounds
  - Computer makes random choices
  - Win/loss/draw detection
  - User-friendly interface

### 7. **To-Do App** (`to_do_app.py`)
Simple task management application.
- **Features:**
  - Create tasks
  - View all tasks
  - Remove tasks
  - Track task count

### 8. **To-Do List with File Handling** (`To_Do_List_usingfilehandling.py`)
Enhanced to-do application with persistent storage.
- **Features:**
  - Save tasks to file
  - Load tasks from file
  - Persistent data storage
  - Demonstrates file I/O operations

### 9. **Practice** (`practice.py`)
General practice file for testing and experimenting with Python concepts.

## 🚀 Getting Started

### Prerequisites
- Python 3.x installed on your system

### Running the Scripts

Each script can be run independently from the command line:

```bash
# Run password generator
python password_generator.py

# Run ATM simulation
python Atm_simulation.py

# Play Rock, Scissors, Paper
python RSP_Game.py

# Use the to-do app
python to_do_app.py
```
